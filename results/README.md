# Results

Made from the responses downloaded on 14 Nov 2026 (main survey: 123 analysed; short survey: 63 analysed).
These files hold only summary numbers and random respondent ids, never UPI ids.

- `main/`: the main survey (index.html), made by `py analysis/analyze.py responses.csv all`. Start with `main/report.txt`.
- `short/`: the short survey (proposal.html), made by `py analysis/analyze_proposal.py responses.csv`. Start with `short/report.txt`.

To refresh them, download the Sheet as CSV, rerun the two commands, and copy `analysis/out/` and `analysis/out/proposal/` here.
